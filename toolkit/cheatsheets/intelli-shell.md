# intelli-shell

> Intelligent shell with pre-populated commands.

## Installation
```bash
curl -sSL https://raw.githubusercontent.com/serkanyersen/intelli-shell/main/install.sh | bash
```

## Usage
```bash
intelli-shell
```

## Features
- Pre-populated command snippets
- Curriculum delivery mechanism
- Easy to customize
