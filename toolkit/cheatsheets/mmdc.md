# mmdc

> Mermaid diagram CLI.

## Installation
```bash
npm install -g @mermaid-js/mermaid-cli
```

## Usage
```bash
mmdc -i diagram.mm -o diagram.png
```

## Features
- Convert Mermaid diagrams to images
- Supports PNG, SVG, and more
- Easy integration with workflows
