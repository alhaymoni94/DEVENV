# diffnav

> Navigate git diffs with ease.

## Installation
```bash
brew install dlvhdr/formulae/diffnav
```

## Usage
```bash
export GIT_PAGER='diffnav'
git diff
```

## Features
- Interactive diff navigation
- Keyboard shortcuts for easy navigation
- Integrates with git
