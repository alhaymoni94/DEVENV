# Phase 1: Foundations Quiz

Q: What command asks AI a quick question from the terminal?
A: ai "your question"

Q: How do you pipe a file's content to AI for analysis?
A: cat file.py | ai "explain this"

Q: What command opens the interactive cheatsheet browser?
A: cheat

Q: What command shows a quick reference card for a tool?
A: qr tool-name

Q: What command shows how to undo a mistake?
A: cheat --undo tool-name

Q: What command takes you to the previous directory?
A: cd -

Q: What does chmod 755 mean for a file?
A: Owner: rwx, Group: r-x, Other: r-x

Q: What command finds all .py files in the current directory?
A: find . -name "*.py"

Q: What does grep -c do?
A: Count matching lines

Q: How do you make a script executable?
A: chmod +x script.sh

Q: What command creates a new tmux session?
A: tmux new -s session-name

Q: How do you detach from a tmux session?
A: Ctrl+B, then D

Q: How do you split a tmux pane vertically?
A: Ctrl+B, then %

Q: How do you split a tmux pane horizontally?
A: Ctrl+B, then "

Q: How do you list all tmux sessions?
A: tmux ls

Q: What command initializes a git repository?
A: git init

Q: How do you stage all changes and commit in one line?
A: git add -A && git commit -m "message"

Q: What command opens the lazygit TUI?
A: lg

Q: How do you create and switch to a new branch?
A: git checkout -b branch-name

Q: How do you undo the last commit but keep changes staged?
A: git reset --soft HEAD~1

Q: What command creates a GitHub PR?
A: gh pr create --fill

Q: How do you stash current changes?
A: git stash

Q: What does git reflog show?
A: All HEAD movements (useful for recovery)

Q: How do you merge a branch into the current branch?
A: git merge branch-name

Q: What alias opens the file manager?
A: y
