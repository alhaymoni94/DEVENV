# Tmux Quiz

Q: What is the prefix key in this config?
A: Ctrl+a

Q: How do you split a pane horizontally?
A: Prefix |

Q: How do you split a pane vertically?
A: Prefix -

Q: How do you create a new window?
A: Prefix c

Q: How do you detach from a session?
A: Prefix d

Q: How do you move between panes without the prefix?
A: Alt+Arrow

Q: How do you kill the current pane?
A: Prefix x

Q: How do you kill the current window?
A: Prefix X

Q: How do you reload the tmux config?
A: Prefix r

Q: How do you attach to a session from the shell?
A: tmux attach -t <name>

Q: How do you resize a pane?
A: Prefix H/J/K/L

Q: How do you enter copy mode?
A: Prefix Enter

Q: What does the PREFIX indicator in the status bar mean?
A: You've pressed Ctrl+a and tmux is waiting for the next key

Q: How do you create a new named session?
A: tmux new -s <name>

Q: How do you list all sessions?
A: tmux ls
