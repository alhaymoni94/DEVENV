# Phase 5: Advanced Topics Quiz

Q: What command starts an opencode coding session?
A: opencode

Q: How do you ask AI to review a script?
A: cat script.sh | ai "review this script"

Q: What Python library generates fake data?
A: Faker

Q: How do you install Faker?
A: pip install faker

Q: What Faker method generates a random name?
A: fake.name()

Q: What Faker method generates a random email?
A: fake.email()

Q: How do you generate 100 fake records with Faker?
A: for _ in range(100): ...

Q: What is synthetic data used for?
A: Testing, ML training, demos, privacy

Q: What command checks if ollama is installed?
A: which ollama

Q: What are the trade-offs of local vs cloud AI models?
A: Cost, privacy, speed, quality

Q: What aichat config setting changes the model?
A: model: in config.yaml

Q: What does temperature control in AI models?
A: Randomness/creativity of responses

Q: What is TDD?
A: Test-Driven Development: write tests first, then code

Q: How do you create a GitHub Actions workflow file?
A: .github/workflows/ci.yml

Q: What gh command creates a PR?
A: gh pr create --fill

Q: What gh command checks PR CI status?
A: gh pr checks

Q: What gh command merges a PR?
A: gh pr merge --squash

Q: How do you generate a pyproject.toml with AI?
A: ai "create a pyproject.toml for this project"

Q: What command renders a project plan as markdown?
A: glow PLAN.md

Q: How do you ask AI to add tests to existing code?
A: cat code.py | ai "write tests for this"
