# Daily Tips
> Run `cheat --daily` for a random tip.

1. `Ctrl+R` searches history. Type part of a command, press `Ctrl+R` again to cycle matches.
2. `sudo !!` reruns the last command with sudo prepended.
3. In tmux, `Prefix |` splits horizontally, `Prefix -` splits vertically. Think of the character as the split direction.
4. `lg` opens lazygit. `Space` stages files, `c` commits, `P` pushes.
5. In yazi, `/` searches filenames. `.` toggles hidden files.
6. `Ctrl+W` deletes the word before cursor in the shell. Faster than holding backspace.
7. `Ctrl+U` clears to the start of line. `Ctrl+K` clears to the end.
8. In micro, `Ctrl+/` toggles comments. Works for most languages.
9. `tmux attach` reattaches to your last session. No need to remember the name.
10. `y` opens yazi and `cd`s to where you quit. `q` quits without changing directory.
11. `Prefix d` detaches from tmux. The session keeps running in the background.
12. `Ctrl+A` and `Ctrl+E` jump to start/end of line. Works in shell and micro.
13. In lazygit, `z` undoes the last git action. Your safety net.
14. `cheat <topic>` opens a cheatsheet. `cheat` alone opens the interactive browser.
15. `Ctrl+L` clears the screen. Same as running `clear`.
16. In tmux, `Alt+Arrow` moves between panes without the prefix.
17. `e filename` opens micro. `e .` opens micro with the file browser.
18. `ghd` opens gh-dash — your PR and issue dashboard.
19. In yazi, `z` uses zoxide to fuzzy-jump to any directory you've visited.
20. `Prefix r` reloads tmux config. No need to restart the session.
21. `Ctrl+Z` suspends the current process. `fg` brings it back.
22. In micro, `Ctrl+D` duplicates the current line. Great for quick edits.
23. `top` runs btop — a beautiful system monitor.
24. In lazygit, `?` shows all keybindings for the current panel.
25. `Ctrl+C` cancels the running command. Your escape hatch.
26. In tmux, `Prefix x` kills the current pane. `Prefix X` kills the window.
27. `lzd` opens lazydocker — manage containers without memorizing docker commands.
28. In yazi, `Space` selects a file and moves down. Hold it to select multiple.
29. `Ctrl+F` finds text in micro. `Ctrl+H` finds and replaces.
30. `Prefix c` creates a new tmux window. Think "new tab."
31. In the shell, `Alt+F` and `Alt+B` jump forward/backward by word.
32. `cheat --quick <tool>` shows a one-pager. `cheat <tool>` shows the full guide.
33. In tmux, `Prefix H/J/K/L` resizes panes. The letters match the direction.
34. `Ctrl+Y` redoes in micro. The opposite of `Ctrl+Z`.
35. In lazygit, `Tab` cycles between panels. `[` and `]` switch tabs within a panel.
36. `y ~/path` opens yazi at a specific path.
37. In micro, `Ctrl+G` goes to a line number.
38. `Ctrl+Q` unfreezes the terminal. You probably hit `Ctrl+S` by accident.
39. In yazi, `Ctrl+Q` quits and cd's. `q` quits without changing directory.
40. `Prefix Enter` enters copy mode in tmux. Scroll with arrow keys, `q` to exit.
41. In the shell, `..` cd's up one level. `...` cd's up two. (AUTO_CD is enabled)
42. `cheat --daily` gives you one random tip. Run it each morning.
43. In micro, `Alt+Click` adds a cursor. Edit multiple places at once.
44. `tmux new -s name` creates a named session. Easier to find later.
45. In yazi, `R` bulk-renames: opens all selected filenames in your editor.
46. `Ctrl+T` creates a new tab in yazi. `Ctrl+W` closes one.
47. In lazygit, `A` amends the last commit with staged changes.
48. `glow file.md` renders markdown in the terminal.
49. In tmux, the status bar shows CPU, RAM, disk, and a PREFIX indicator.
50. The entire stack is managed by chezmoi. `chezmoi apply` syncs everything.
51. `aichat` starts a conversational AI session right in your terminal.
52. `cat file.py | aichat "explain this code"` pipes any output to AI for analysis.
53. In aichat, `/role coder` switches to a coding-focused persona.
54. `aichat -m ollama:llama3` uses a local model — no API key needed.
55. In aichat, `/save conversation.md` saves the entire chat to a file.
