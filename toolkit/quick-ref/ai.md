# AI Quick Ref
> Terminal-native AI chat. Run `cheat ai` for the full guide.

| I want to...                  | Do this                          |
|-------------------------------|----------------------------------|
| Start chat session            | `ai`                             |
| One-shot question             | `ai "your question"`             |
| Pipe input to AI              | `cat file.py \| ai`              |
| Explain code                  | `cat file.py \| ai "explain"`    |
| Use system prompt             | `ai --system "role" "question"`  |
| Save output                   | `ai "question" > answer.md`      |
| Exit session                  | `Ctrl+D` or `/exit`              |
