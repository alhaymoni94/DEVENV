# Mermaid CLI Quick Ref
> Render Mermaid diagrams. Run `cheat mmdc` for the full guide.

| I want to...                  | Do this                          |
|-------------------------------|----------------------------------|
| Render diagram to PNG         | `mmdc -i diagram.mmd -o out.png` |
| Render to SVG                 | `mmdc -i diagram.mmd -o out.svg` |
| Set theme                     | `mmdc -i in.mmd -o out.png -t dark` |
| Set background                | `mmdc -i in.mmd -o out.png -b transparent` |
