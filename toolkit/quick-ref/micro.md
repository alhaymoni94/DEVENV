# Micro Quick Ref
> Top 10 most-used editor actions. Run `cheat micro` for the full guide.

| I want to...                  | Do this                          |
|-------------------------------|----------------------------------|
| Save                          | `Ctrl+S`                         |
| Quit                          | `Ctrl+Q`                         |
| Undo                          | `Ctrl+Z`                         |
| Redo                          | `Ctrl+Y`                         |
| Find                          | `Ctrl+F`                         |
| Find and replace              | `Ctrl+H`                         |
| Copy / Cut / Paste            | `Ctrl+C` / `Ctrl+X` / `Ctrl+V`  |
| Toggle comment                | `Ctrl+/`                         |
| Duplicate line                | `Ctrl+D`                         |
| Go to line number             | `Ctrl+G`                         |

**Multiple cursors:** `Alt+Click` to add · `Ctrl+Up/Down` for above/below · `Escape` to collapse
