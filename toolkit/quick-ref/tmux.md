# Tmux Quick Ref
> Prefix = `Ctrl+a`. Run `cheat tmux` for the full guide.

| I want to...                  | Do this                          |
|-------------------------------|----------------------------------|
| Split horizontal              | `Prefix \|`                      |
| Split vertical                | `Prefix -`                       |
| New window (tab)              | `Prefix c`                       |
| Detach (session keeps running)| `Prefix d`                       |
| Move between panes            | `Alt+Arrow`                      |
| Kill pane                     | `Prefix x`                       |
| Kill window                   | `Prefix X`                       |
| Resize pane                   | `Prefix H/J/K/L`                 |
| Reload config                 | `Prefix r`                       |
| Attach to session             | `tmux attach -t name`            |

**Status bar:** CPU · RAM · Disk · PREFIX indicator · date · time
