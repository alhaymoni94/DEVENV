# Treemd Quick Ref
> Markdown tree generator. Run `cheat treemd` for the full guide.

| I want to...                  | Do this                          |
|-------------------------------|----------------------------------|
| Generate tree from directory  | `treemd ./path`                  |
| Output to file                | `treemd ./path > tree.md`        |
| Include hidden files          | `treemd -a ./path`               |
| Set max depth                 | `treemd -d 3 ./path`             |
