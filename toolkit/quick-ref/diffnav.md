# Diffnav Quick Ref
> Git diff navigator. Run `cheat diffnav` for the full guide.

| I want to...                  | Do this                          |
|-------------------------------|----------------------------------|
| Navigate git diff             | `diffnav`                        |
| Go to next hunk               | `j` / `↓`                        |
| Go to previous hunk           | `k` / `↑`                        |
| Stage current hunk            | `s`                              |
| Unstage current hunk          | `u`                              |
| Quit                          | `q`                              |
