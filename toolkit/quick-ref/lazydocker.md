# Lazydocker Quick Ref
> Open with `lzd`. Run `cheat lazydocker` for the full guide.

| I want to...                  | Do this                          |
|-------------------------------|----------------------------------|
| Start/stop container          | `Space`                          |
| View container logs           | `Enter`                          |
| Remove container              | `d`                              |
| Restart container             | `e`                              |
| View container stats          | `s`                              |
| Switch panels                 | `Tab`                            |
| View all keybindings          | `?`                              |
| Quit                          | `q`                              |

**Quick Docker CLI:** `docker ps` · `docker images` · `docker logs <container>`
