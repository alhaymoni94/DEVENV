# Alias Reference
> Grouped by how often you'll use them. Learn top-to-bottom.

---

## Daily — Muscle Memory

| Alias | Expands to | When you'll use it |
|-------|-----------|-------------------|
| `e`   | `micro`   | Every time you edit a file |
| `y`   | `yazi`    | Every time you browse files |
| `lg`  | `lazygit` | Every time you commit or check git status |
| `ai`  | `aichat`  | Every time you need AI help |

**Focus:** These should become automatic. Use them constantly until you don't think about them.

---

## Weekly — Regular Tools

| Alias | Expands to | When you'll use it |
|-------|-----------|-------------------|
| `lzd` | `lazydocker` | When managing containers |
| `ghd` | `gh dash` | When checking PRs, issues, review requests |
| `top` | `btop`    | When checking system resources |

**Focus:** You'll reach for these naturally when the situation calls for them. No need to force memorization.

---

## Occasional — Look Them Up

| Alias | Expands to | When you'll use it |
|-------|-----------|-------------------|
| `qr`  | `cheat --quick` | When you need a one-pager reference |
| `tip` | `cheat --daily` | When you want a random pro tip |

**Focus:** Don't memorize these. Remember that `cheat` exists and look them up when needed.

---

## Setup — Maintenance

| Alias | Expands to | When you'll use it |
|-------|-----------|-------------------|
| `stack-update`  | Run stack update script | When updating all tools at once |
| `stack-backup`  | Create config backup | Before major changes, or weekly |
| `stack-restore` | Restore from backup | When recovering from a broken config |

**Focus:** Run `stack-backup` before making big changes. That's it.

---

## Learning Path

```
Week 1:  e, y, lg          ← Your core workflow
Week 2:  ai, top            ← Add AI and monitoring
Week 3:  lzd, ghd           ← Add Docker and GitHub
Week 4:  qr, tip            ← Discover the cheat system
Ongoing: stack-* aliases    ← Maintenance when needed
```

**Rule:** Don't try to learn everything at once. Master the daily aliases first. The rest will come naturally.
