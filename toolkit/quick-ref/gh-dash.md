# GH-Dash Quick Ref
> Open with `ghd`. Run `cheat gh-dash` for the full guide.

| I want to...                  | Do this                          |
|-------------------------------|----------------------------------|
| View PRs                      | `ghd` → PRs tab                  |
| View issues                   | `ghd` → Issues tab               |
| View review requests          | `ghd` → Reviews tab              |
| Open PR in browser            | `o`                              |
| Check out PR locally          | `c`                              |
| View PR diff                  | `d`                              |
| Refresh                       | `r`                              |
| Quit                          | `q`                              |
