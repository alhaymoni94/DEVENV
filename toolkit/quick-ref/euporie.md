# Euporie Quick Ref
> TUI Jupyter notebooks. Run `cheat euporie` for the full guide.

| I want to...                  | Do this                          |
|-------------------------------|----------------------------------|
| Start notebook                | `euporie`                        |
| Run cell                      | `Ctrl+Enter`                     |
| Add cell below                | `b`                              |
| Add cell above                | `a`                              |
| Delete cell                   | `dd`                             |
| Edit cell                     | `Enter`                          |
| Save notebook                 | `Ctrl+S`                         |
| Quit                          | `Ctrl+Q`                         |
