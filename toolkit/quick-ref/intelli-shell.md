# Intelli-Shell Quick Ref
> Command suggestion and history. Run `cheat intelli-shell` for the full guide.

| I want to...                  | Do this                          |
|-------------------------------|----------------------------------|
| Search stored commands        | `Ctrl+Space`                     |
| Bookmark a new command        | `Ctrl+B`                         |
| Replace variables in command  | `Ctrl+L`                         |
| Fix a failing command         | `Ctrl+X`                         |
| Import commands               | `intelli-shell import file.yml`  |
| Export commands               | `intelli-shell export > file.yml`|
