# D2 Quick Ref
> Diagram markup language. Run `cheat d2` for the full guide.

| I want to...                  | Do this                          |
|-------------------------------|----------------------------------|
| Render diagram to PNG         | `d2 diagram.d2 output.png`       |
| Render to SVG                 | `d2 diagram.d2 output.svg`       |
| Watch mode (auto-re-render)   | `d2 --watch diagram.d2 out.png`  |
| Set layout engine             | `d2 --layout=elk in.d2 out.png`  |
