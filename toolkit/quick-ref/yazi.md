# Yazi Quick Ref (CUA)
> Open with `y`. Run `cheat yazi` for the full guide.

| I want to...                  | Do this                          |
|-------------------------------|----------------------------------|
| Navigate                      | `↑` / `↓`                        |
| Enter dir / open file         | `→` / `Enter`                    |
| Go to parent                  | `←`                              |
| Copy / Cut / Paste            | `Ctrl+C` / `Ctrl+X` / `Ctrl+V`  |
| Toggle select                 | `Space`                          |
| Select all                    | `V`                              |
| Trash                         | `d`                              |
| Create file/dir               | `a` (`dirname/` for dir)         |
| Rename                        | `r`                              |
| Quit + cd to current dir      | `Ctrl+Q`                         |

**Search:** `/` find · `f` filter · `z` zoxide jump · `.` toggle hidden
