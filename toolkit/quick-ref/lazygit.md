# Lazygit Quick Ref
> Open with `lg`. Run `cheat lazygit` for the full guide.

| I want to...                  | Do this                          |
|-------------------------------|----------------------------------|
| Stage/unstage file            | `Space`                          |
| Stage all                     | `a`                              |
| Commit                        | `c` → type message → `Enter`     |
| Push / Pull                   | `P` / `p`                        |
| New branch                    | `n` → name it                    |
| Checkout branch               | `Space` on branch                |
| Undo last action              | `z`                              |
| Amend last commit             | `A` (after staging)              |
| View all keybindings          | `?`                              |
| Quit                          | `q`                              |

**Panels:** `Tab` to cycle · `[`/`]` to switch tabs within a panel
