# Aichat Quick Ref
> Terminal-native AI chat. Run `cheat aichat` for the full guide.

| I want to...                  | Do this                          |
|-------------------------------|----------------------------------|
| Start chat session            | `aichat`                         |
| One-shot question             | `aichat "your question"`         |
| Pipe input to AI              | `cat file.py \| aichat`          |
| Explain code                  | `cat file.py \| aichat "explain"`|
| Use specific model            | `aichat -m ollama:llama3`        |
| Change role/system prompt     | `/role <name>` in session        |
| Save conversation             | `/save <file>` in session        |
| View all commands             | `/help` in session               |
| Exit session                  | `Ctrl+D` or `/exit`              |
