# Opencode Quick Ref
> AI coding agent. Run `cheat opencode` for the full guide.

| I want to...                  | Do this                          |
|-------------------------------|----------------------------------|
| Start coding session          | `opencode`                       |
| Ask about project             | Type question in session         |
| Generate code                 | "write a function that..."       |
| Debug an issue                | "why is this failing..."         |
| Refactor code                 | "refactor this to..."            |
| Exit session                  | `Ctrl+D` or `/exit`              |

**One-shot mode:** Use `ai "question"` or `cat file | ai "prompt"` for quick answers without opening the TUI.
