# Visidata Quick Ref
> Open with `vd file.csv`. Run `cheat visidata` for the full guide.

| I want to...                  | Do this                          |
|-------------------------------|----------------------------------|
| Open CSV/JSON file            | `vd file.csv`                    |
| Sort column                   | Click column header or `g+`/`g-` |
| Filter rows                   | `|` → type condition             |
| Select columns                | `!` on column                    |
| Edit cell                     | `e`                              |
| Save modified sheet           | `Ctrl+S`                         |
| Show all keybindings          | `gz`                             |
| Quit                          | `q`                              |
