# Glow Quick Ref
> Render markdown in the terminal. Run `cheat glow` for the full guide.

| I want to...                  | Do this                          |
|-------------------------------|----------------------------------|
| Render a markdown file        | `glow file.md`                   |
| Render scrollable             | `glow -p file.md`                |
| Render from stdin             | `cat file.md | glow`             |
| Render from URL               | `glow https://url/README.md`     |
| Set width                     | `glow -w 80 file.md`             |

**Used by:** cheat script renders all cheatsheets via glow
