# Shell Quick Ref
> Top 10 most-used shell actions. Run `cheat shell` for the full guide.

| I want to...                  | Do this                          |
|-------------------------------|----------------------------------|
| Search command history        | `Ctrl+R` → type → `Enter`        |
| Go to start of line           | `Ctrl+A`                         |
| Go to end of line             | `Ctrl+E`                         |
| Delete word before cursor     | `Ctrl+W`                         |
| Delete to start of line       | `Ctrl+U`                         |
| Delete to end of line         | `Ctrl+K`                         |
| Clear screen                  | `Ctrl+L`                         |
| Rerun last command as sudo    | `sudo !!`                        |
| Cancel current command        | `Ctrl+C`                         |
| Suspend and resume later      | `Ctrl+Z` → `fg` to resume        |

**Aliases:** `lg` (lazygit) · `lzd` (lazydocker) · `ghd` (gh dash) · `top` (btop) · `e` (micro) · `y` (yazi)
