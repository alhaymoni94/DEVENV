# Btop Quick Ref
> Open with `top`. Run `cheat btop` for the full guide.

| I want to...                  | Do this                          |
|-------------------------------|----------------------------------|
| Sort by CPU                   | `p`                              |
| Sort by memory                | `m`                              |
| Kill a process                | `k` → select signal              |
| Filter processes              | `/` → type filter                |
| Clear filter                  | `Esc`                            |
| Expand process tree           | `Enter`                          |
| Change theme                  | `t`                              |
| Toggle disk graph             | `d`                              |
| Toggle network graph          | `n`                              |
| Quit                          | `q`                              |

**Tip:** tmux status bar shows CPU/RAM/disk at a glance — use btop for detail.
