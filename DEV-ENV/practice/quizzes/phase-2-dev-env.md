# Phase 2: Dev Environment Quiz

Q: What command opens a file in micro?
A: e filename

Q: How do you save in micro?
A: Ctrl+S

Q: How do you find and replace in micro?
A: Ctrl+H

Q: How do you duplicate a line in micro?
A: Ctrl+D

Q: How do you toggle comments in micro?
A: Ctrl+/

Q: What command checks which dotfiles are managed by chezmoi?
A: chezmoi managed

Q: What command shows what changes chezmoi will make?
A: chezmoi diff

Q: What command applies chezmoi configurations?
A: chezmoi apply

Q: What command adds a new file to chezmoi management?
A: chezmoi add ~/.config/file

Q: What file controls the starship prompt appearance?
A: ~/.config/starship/starship.toml

Q: How do you reload tmux config without restarting?
A: tmux source-file ~/.tmux.conf

Q: What command shows all available cheatsheets?
A: cheat --list

Q: What command shows a random pro tip?
A: tip

Q: What command runs a quiz for a topic?
A: cheat --quiz topic

Q: What command opens a workflow guide?
A: cheat --workflow name

Q: What command opens the directory browser in micro?
A: e .

Q: How do you switch between open files in micro?
A: Ctrl+Tab

Q: What starship segment shows git branch and status?
A: [git_status]

Q: What does chezmoi status show?
A: Files out of sync between source and target

Q: How do you edit a chezmoi-managed file?
A: chezmoi edit filename
