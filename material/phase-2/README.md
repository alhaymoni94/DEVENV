# Phase 2: Development Environment

## Overview

Phase 2 focuses on building an efficient, personalized development environment. Students learn to master their editor, manage dotfiles, and build a self-documenting workflow with the cheat system.

## Lessons

| # | Topic | Duration | Key Tools |
|---|-------|----------|-----------|
| 5 | Editor Mastery | 2 hours | micro, keybindings, plugins |
| 6 | Dotfiles & Config Management | 1.5 hours | chezmoi, starship, tmux |
| 7 | Cheat System & Self-Documentation | 1 hour | cheat, workflows, quick-refs |

## Learning Objectives

By the end of Phase 2, students will be able to:
- Edit files efficiently with keyboard-only workflows
- Manage configurations with chezmoi (version-controlled dotfiles)
- Customize their starship prompt and terminal appearance
- Use the cheat system for self-directed learning
- Document their own workflows for future reference

## Prerequisites

- Phase 1 completed
- Comfortable with basic terminal navigation

## Assessment

- Personalized dotfiles configuration
- Custom starship prompt
- Completed cheat system walkthrough
- Personal workflow documentation
