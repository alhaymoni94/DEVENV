# Phase 6: Workspace Automation

## Overview

Phase 6 teaches students to automate their entire workspace — syncing data, running diagnostics, importing/exporting configurations, and building custom automation scripts.

## Lessons

| # | Topic | Duration | Key Tools |
|---|-------|----------|-----------|
| 18 | Workspace Automation | 2 hours | bash, cron, chezmoi, custom scripts |

## Learning Objectives

By the end of Phase 6, students will be able to:
- Write scripts that sync and backup their workspace
- Create diagnostic scripts for their environment
- Automate repetitive tasks
- Build a fully automated development workflow

## Prerequisites

- All previous phases completed
