# Lesson 16: AI Models Management — Instructor Guide

## Duration: 2 hours

## Objectives

By the end of this lesson, students will:
- Understand local vs cloud AI models
- Configure AI tools for different use cases
- Evaluate model performance
- Understand trade-offs (cost, speed, quality)

## Prerequisites

- Phase 4 completed
- AI tools configured

## Lesson Flow

### Part 1: Model Landscape (25 min)

**Cover:**
- Cloud models: GPT-4, Claude, Gemini
- Open-source: Llama, Mistral, Phi
- Local inference: ollama, llama.cpp
- Trade-offs: cost vs privacy vs quality

### Part 2: Configuration Deep Dive (25 min)

**Cover:**
- aichat config: `~/.config/aichat/config.yaml`
- System prompts
- Temperature, top_p, max_tokens
- Switching models per task

### Part 3: Model Evaluation (30 min)

**Have students test models on:**
1. Coding tasks
2. Reasoning
3. Creativity
4. Code review
5. Data analysis

### Part 4: Cost Management (20 min)

**Cover:**
- Token counting
- Cost per model
- Budget tracking
- When to use cheaper models

## Assessment

- Students understand model options
- Students configure AI tools
- Students evaluate model performance
