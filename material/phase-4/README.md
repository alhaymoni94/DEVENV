# Phase 4: Containerization & AI

## Overview

Phase 4 introduces Docker for containerization and local AI development. Students learn to containerize applications, manage multi-container setups, and run AI models locally.

## Lessons

| # | Topic | Duration | Key Tools |
|---|-------|----------|-----------|
| 11 | Docker Basics | 2 hours | docker, lazydocker |
| 12 | Docker Compose | 2 hours | docker compose, lazydocker |
| 13 | Local AI Development | 2 hours | ollama, opencode, ai |

## Learning Objectives

By the end of Phase 4, students will be able to:
- Build and run Docker containers
- Create Dockerfiles for their applications
- Use Docker Compose for multi-container apps
- Manage containers with lazydocker
- Run AI models locally

## Prerequisites

- Phase 3 completed
- Docker installed (verified by doctor.sh)

## Assessment

- Containerize a simple application
- Create a docker-compose.yml for a multi-container app
- Run a local AI model
