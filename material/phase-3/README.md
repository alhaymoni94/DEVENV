# Phase 3: Data Manipulation & AI

## Overview

Phase 3 teaches students to handle data entirely from the terminal — CSV, JSON, SQL, spreadsheets — and use AI to automate data workflows.

## Lessons

| # | Topic | Duration | Key Tools |
|---|-------|----------|-----------|
| 8 | Data Formats in the Terminal | 2 hours | visidata, glow, jq |
| 9 | Data Manipulation with AI | 2 hours | aichat, awk, sed, visidata |
| 10 | Shell Scripting for Automation | 2 hours | bash, zsh, cron |

## Learning Objectives

By the end of Phase 3, students will be able to:
- Open and analyze CSV, JSON, and other data formats in the terminal
- Use visidata for spreadsheet-like analysis
- Use AI to transform and clean data
- Write shell scripts for repetitive data tasks
- Automate workflows with cron

## Prerequisites

- Phase 2 completed
- Comfortable with basic shell commands

## Assessment

- Analyze a real dataset using visidata
- Transform data between formats using AI
- Write an automation script
