# Phase 1: Foundations with AI Assistance

## Overview

Phase 1 introduces students to the terminal environment and AI-assisted workflows from day one. Students will learn to navigate the terminal, manage files, use tmux for productivity, and work with git — all while using AI agents as their learning assistants.

## Lessons

| # | Topic | Duration | Key Tools |
|---|-------|----------|-----------|
| 1 | AI Agents in the Terminal | 1.5 hours | aichat, opencode, cheat |
| 2 | Unix Fundamentals | 2 hours | zsh, micro, yazi, fzf |
| 3 | Tmux Mastery | 1.5 hours | tmux |
| 4 | Git Workflow | 2 hours | lazygit, gh, git |

## Learning Objectives

By the end of Phase 1, students will be able to:
- Ask AI agents questions directly from the terminal
- Navigate the file system without a mouse
- Edit files efficiently in a terminal editor
- Manage terminal sessions with tmux
- Use git for version control with a TUI
- Use the cheat system for self-directed learning

## Assessment

- **Lab completion**: Each lesson has a hands-on lab
- **Quiz**: Each lesson ends with a quiz (`cheat --quiz <topic>`)
- **Practical exam**: Students complete a real-world task combining all skills

## Setup Requirements

- `setup.sh` completed with 40/40 health
- AI API key configured for `aichat`
- GitHub account for `gh` authentication
