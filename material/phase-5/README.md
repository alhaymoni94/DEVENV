# Phase 5: Advanced Topics

## Overview

Phase 5 covers advanced terminal-based AI workflows, synthetic data generation, AI model management, and AI-assisted software development lifecycle.

## Lessons

| # | Topic | Duration | Key Tools |
|---|-------|----------|-----------|
| 14 | TUI Coding Agents | 2 hours | opencode, aichat, intelli-shell |
| 15 | Synthetic Data Generation | 2 hours | Python, Faker, AI agents |
| 16 | AI Models Management | 2 hours | ollama, huggingface, mise |
| 17 | SDLC Using AI Agents | 2 hours | opencode, gh, docker, CI/CD |

## Learning Objectives

By the end of Phase 5, students will be able to:
- Use TUI coding agents for complex development tasks
- Generate and evaluate synthetic data
- Manage local AI models
- Build AI-assisted CI/CD pipelines
- Automate the full software development lifecycle

## Prerequisites

- Phase 4 completed
- Comfortable with Docker and AI tools
